# Data-Meets-Psychology

Data Meets Psychology — Exploring How Personality Shapes Our Social Behavior
Project Overview

This Power BI project explores the intersection of data and psychology, analyzing how personality traits influence habits, energy patterns, and career choices. Instead of treating personality as a label, this project uses data-driven insights to understand behavior.

Key Findings

Personality Distribution: 51.4% Extroverts | 48.6% Introverts — nearly balanced but with very different patterns.

Alone Time: Introverts spend an average of 7 hours alone, extroverts just 2.

Social Energy: 92% of introverts feel drained after socializing, compared to only 7.4% of extroverts.

Friendship Patterns: Extroverts average 9 friends, introverts maintain 3 close friends.

Digital Expression: Introverts with high alone time post more online, using digital space as a self-expression outlet.

Behavioral Insights

Understanding personality traits allows for intentional decision-making:

Introverts: Excel in analytical, creative, or research-based roles that benefit from deep focus and independent thinking.

Extroverts: Thrive in leadership, communication, or collaborative environments where energy flows through interaction.

Personality is not a limitation but a roadmap for strategic growth.

Takeaway

This project highlights that data can illuminate human behavior, allowing us to make smarter choices about work, learning, and personal growth. By understanding behavioral patterns, we can optimize energy, relationships, and career trajectories.

This project is a blend of data analytics and psychological insight, demonstrating my ability to translate complex datasets into meaningful, actionable narratives.
